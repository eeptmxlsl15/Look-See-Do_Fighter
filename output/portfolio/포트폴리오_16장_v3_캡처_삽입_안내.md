# 포트폴리오 캡처 삽입 안내

대상: `김석진_LSDF_AI_Native_포트폴리오_16장_v3.pptx`

16장 본문은 편집 가능한 텍스트·도식·표로 구성했습니다. 사용자가 제공한 원문 전체와 관련 프로젝트 파일 경로는 각 슬라이드의 발표자 노트에 보존했습니다. PDF는 슬라이드 본문만 포함합니다.

## 화면을 넣을 위치

| 슬라이드 | 권장 캡처 | 화면에 포함하면 좋은 내용 |
|---|---|---|
| 03 — 게임 시스템 | 기술 선택 또는 실제 대전 화면 | 28슬롯 기술 구성, 비용·예산 또는 캐릭터 두 명과 HUD |
| 08 — 라운드·매치 | 매치 결과 또는 라운드 전환 | 실제 3:2 결과가 있으면 우선 사용. 없으면 Round/Fight 전환 화면 사용 |
| 11 — 전투 피드백 | 피격 또는 카운터 순간 | 피격 이펙트, 체력바, 카메라 구도 |
| 12 — 스테이지·UI | 실제 HUD 또는 설정 Inspector | 이미지 체력바·승수 표시, 또는 Sprite·비율·반전 설정 |

모든 캡처 영역은 16:9 비율의 PowerPoint 기본 **그림 자리 표시자**입니다. 게임 실행 화면을 임의로 합성하지 않았습니다. 10장의 두 캐릭터 이미지는 프로젝트 원본 동작 에셋이며, pivot 수정 전후나 실제 실행 증거를 의미하지 않습니다.

## 넣는 방법

1. PPTX를 Microsoft PowerPoint에서 열고 해당 슬라이드로 이동합니다.
2. 회색 영역 중앙의 **그림 삽입 아이콘**을 눌러 캡처 파일을 선택합니다. 아이콘이 보이지 않으면 자리 표시자 안을 클릭합니다.
3. `그림 서식 → 자르기`에서 화면을 조절합니다. 전체 화면 정보가 필요하면 `맞춤`, 여백 없이 채우려면 `채우기`를 선택합니다. 이미지를 가로·세로로 늘리지 않습니다.
4. 캡처 아래의 “넣어 주세요” 안내 문장을 실제 화면 설명으로 바꾸거나 삭제합니다. 위의 영문 CAPTURE 라벨도 “실제 대전 화면” 등으로 바꿀 수 있습니다.
5. 저장한 뒤 `파일 → 내보내기 → PDF/XPS 만들기`로 PDF를 다시 만듭니다. 배포용 PDF는 그림 삽입 후 생성한 버전을 사용합니다.

1920×1080 이상 캡처를 권장합니다. Inspector는 관련 항목만 잘라 넣되 글자를 읽을 수 있도록 범위를 제한합니다. 플레이어 이름·계정·채팅 등 제출에 불필요한 개인정보는 캡처 전에 가립니다. 실제 확보하지 않은 점수·테스트 결과를 만들어 넣지 않습니다.

## 편집 시 유지할 기준

- 슬라이드 크기: 13.333 × 7.5인치, 16:9.
- 글꼴: 전체 맑은 고딕(Malgun Gothic). 제작 환경에서 원본 폰트로 렌더링했습니다.
- 표·화살표·상자·텍스트는 직접 편집할 수 있습니다. 표지 외 제목·부제·챕터 위치는 고정돼 있습니다.
- 발표자 노트 보기: 하단 `노트`를 열거나 `보기 → 노트 페이지`. 원문 전체와 출처·검증 한계가 들어 있습니다.
- 9장의 실패/후속 미검증, 15장의 서로 다른 테스트 결과를 합산하지 않는 설명, 16장의 미완료 과제는 제출본에서도 유지합니다.
- 게임 코드·씬·설정 변경이나 커밋·Push는 이번 프레젠테이션 제작에 포함하지 않았습니다.
