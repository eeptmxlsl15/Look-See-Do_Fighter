## 문제와 변경

시작 규칙과 개별 작업 기록은 있었지만 최신 작업·미검증 상태를 찾는 공통 진입점이 없었다.
또한 SessionStart 명령의 `git rev-parse` 또는 실행기 내부 `git status`가 소유권 오류로 실패하면 인수인계 안내가 누락됐다.

- [현재 작업 상태](current-state.md)에 최근 기록/증거, 보존할 로컬 변경, 게임의 미완료·검증 상태, 다음 작업을 정리했다.
- [AGENTS.md](../../AGENTS.md)에 새 세션·재개·압축 후 필수 읽기와 작업 종료·인계 시 요약 갱신을 추가했다.
  README/Skill/AI_SETUP/개발 운영 지침을 연결하고 초기 감사가 과거 스냅샷임을 첫머리에 명시했다.
- [훅 설정](../../.codex/hooks.json)은 Git 대신 현재 경로의 상위 프로젝트 표식으로 실행기를 찾는다.
- [실행기](../../tools/ai/quantum_guard.py)는 Git 실패 시 오류와 `UNKNOWN`을 표시하면서 같은 시작 안내를 전달한다.
  요약 누락도 명시한다. Git 신뢰 설정을 자동 변경하지 않으며 훅은 읽기 전용이다.
- [테스트](../../tools/ai/tests/test_quantum_guard.py)에 소유권 오류/실행 파일 누락/시간 초과, 요약 누락,
  실제 등록 명령의 재개·압축 등 5개 source, Git 저장소가 없는 fixture의 루트/하위 경로 실행과 파일 불변 사례를 포함했다.

게임 소스/설정/기존 증거는 변경하지 않았다. 미추적 작업물을 로컬 기록에 연결했으며 staging·커밋·Push는 수행하지 않는다.
이번 요청은 인수인계 설정 보완이다. 기존 게임의 온라인 착지 실패를 해결하거나 재검증한 작업으로 표현하지 않는다.
