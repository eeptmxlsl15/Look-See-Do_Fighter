## 중단과 다음 단계

AGENTS.md의 “실패해도 자동 재검증 루프를 돌리지 않는다”, “수정 후 미검증이면 자동 커밋·업로드를 중단한다”를 따른다.
[게시 스킬](../../.agents/skills/publish-unity-pr/SKILL.md)도 “수정 후에는 `수정 후 미검증`으로 중단하고 사용자의 새 검증 요청을 기다린다”고 정한다.
실패한 공백 검사는 재실행하지 않았다. 수정은 메타의 행 끝 공백과 JSON EOF 빈 줄에 한정하고 GUID/설정과 JSON 값을 보존했다.
위 수정 후 검사되지 않은 후보를 자동 커밋하거나 Push하지 않는다. 게시 승인은 이미 받았으며 같은 Push 승인을 다시 묻지 않는다.
다음 사용자 재검증 요청 때 공백 검사만 현재 후보에 한 차례 실행하고, 통과하면 기존 129 PASS/컴파일/정적/바이너리 검토를 재사용해 커밋·Push한다.
과거 실패한 게임 fixture와 강제 네트워크 rollback은 별도 미해결 상태로 유지한다.
