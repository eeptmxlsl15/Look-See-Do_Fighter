# 추가타 없는 시동기 이후 자연 낙하

## 원인과 수정

재타격용 모션을 추가하면서 첫 시동기에도 `Hovering → Returning → SlowFalling`을 적용했다.
추가 공격이 없어도 기준 높이까지 정해진 속도로 내려온 뒤 더 느린 일정 속도로 바뀌어,
일반 중력 낙하와 다른 속도 변화가 생겼다. 사용자 보고와 이 소스 경로를 근거로 수정했다.

이번에는 첫 시동기의 상승/체공이 끝나면 **Falling**으로 전환한다.
저장해 둔 몸체 원래 중력 배율을 복구하고 정점의 세로 속도 0에서 물리 중력으로 가속한다.
그 뒤의 세로 속도는 콤보 컨트롤러가 덮어쓰지 않는다. 추가타 없이 내려올 때 Combo Height를
거치거나 기준 높이 아래에서 일정한 저속으로 바뀌지 않는다.

공중에서 실제로 후속타를 맞으면 기존 `RehitRising → Returning → SlowFalling`을 사용한다.
자연 낙하 중 후속타가 맞아도 같은 경로로 연결되며 타수와 원래 중력 배율을 보존한다.
시동타 제외 후속타 5회 제한/지정 마무리/벽 반응/착지·KO·라운드 초기화는 유지한다.

## 설정과 경계

게임 Config 수치는 바꾸지 않았다. 현재 `처음 머무는 시간` 30틱은 첫 낙하가 시작되는 시점을 정한다.
첫 체공 뒤 낙하에는 캐릭터 몸체의 원래 중력이 적용된다.
`Combo Height`, 추가 상승/복귀/느린 낙하 설정은 실제 재타격 모션에 계속 사용한다.

변경은 기존 LSDFJuggle 단계 전환과 설정 안내, 회귀 검사에 한정한다.
QTN 레이아웃과 생성 코드는 이번 요청에서 수정하지 않았고 시스템/물리/Animator/히트박스 수명 순서도 유지한다.
매칭 버전은 `lsdf-loadout-v9-natural-launch-fall`로 올려 다른 낙하 규칙의 클라이언트와 분리한다.
공유 에셋에 실행 상태를 쓰지 않고 기존 Frame 컴포넌트를 사용한다.

## 최종 한 차례 검증

단위 검사에서 첫 체공 뒤 중력 복구/정점 속도/가속 낙하, 낙하 중 재타격 재시작과 기존 아크를 확인한다.
Photon 시나리오는 두 플레이어 각각 **시동타만 맞기 / 자연 낙하 중 후속타 맞기** 총 4개 구간을 실행한다.
확정 프레임 체크섬과 같은 입력 재생 2회를 비교하고 자연 낙하 중/재타격 상승 중 Frame 복원 후 재시뮬레이션한다.
온라인 fixture는 연결 가능한 시간 확보를 위해 세션 시작 전에 첫 체공을 120틱으로 고정하고 종료 후 복원한다.
실제 Config/2P 테스트 입력/IDE 사용자 변경은 보존하며 설정 파일을 테스트에서 저장하지 않는다.

결과는 `evidence/natural-launch-fall-validation.json`에 기록한다. 실제 화면의 자연스러움에 대한 수동 평가,

probe를 서로 다른 연속 틱에서 실제 하강 가속을 한 번 이상 관측해야 하는 조건으로 바꿨다.
원래 중력 복구/자연 낙하 중 착지/추가타 없음/재타격 아크 유지 조건도 계속 요구한다.
이는 검사 조건의 보정이며, 원인 확정이나 수정 성공으로 기록하지 않는다.
운영 코드·설정은 최종 검사 후 바꾸지 않았고 probe 수정 후 자동 재실행하지 않았다.
따라서 자연 낙하의 소스/단위 근거와 온라인에서의 관측 성공을 구별하며 최종 화면 평가는 남아 있다.
