# 도트 배경을 캐릭터와 같은 비율로 축소 — 2026-10-22

기준: `dev/Prototype`, HEAD `debf379c006e40a9a4e00884db3d27bfd111a4d9`.
사용자 요청: 캐릭터 사이가 멀어져 카메라가 물러날 때 평면 맵도 같은 비율로 작아져야 한다.
[최초 배경 구현](stage-background.md)의 자동 화면 채우기는 이 요구에 맞지 않았다.

## 원인과 수정

- 이전 코드는 매 프레임 현재 카메라의 뷰포트를 덮도록 배경 높이를 다시 계산했다.
  줌아웃 때 이미지가 확대되어 축소 효과가 상쇄됐다. Z ±4의 먼 배경 평면 자체도 캐릭터의 Z=0과 다른 원근 비율을 만들었다.
- [LSDFStageBackground](../../Assets/QuantumUser/View/LSDFStageBackground.cs)는 렌더링 평면을 뒤쪽에 유지하면서
  그림의 모든 점을 캐릭터 평면에 놓인 것과 같은 화면 좌표로 투영한다. 카메라 중심의 등비 변환으로 배경의 위치·배율을 보정한다.
  따라서 카메라 이동·피격 흔들림·거리 줌과 FOV 변경에서 캐릭터와 배경 랜드마크가 같은 비율로 움직인다.
  직교 카메라에서는 깊이 보정을 하지 않고 동일한 월드 크기를 유지한다.
- 기존 가까운 거리의 이미지 크기·위치를 유지하기 위해 `Reference Camera Distance` 기본 0.8을 사용한다.
  이는 현재 카메라 추적 코드의 기본 거리와 같으며, `Minimum Height`·`Depth`·`Offset`의 기존 값을 바꾸지 않는다.
- `FillCameraView` 직렬화 필드를 보존하고 Inspector 표시를 `Fit Reference View`로 바꿨다.
  기준 거리에서 렌즈/화면 경계를 한 번 포착한다. 실제 추적/줌/흔들림 위치는 다시 채우는 기준으로 쓰지 않는다.
  화면 비율·카메라·투영 종류·기준 거리·Depth·스테이지 Transform이 바뀌면 기준 경계를 갱신한다.
  FOV/직교 크기만 바뀌면 포착된 구도를 유지하여 렌즈 줌도 배경에 반영한다.
- [Inspector](../../Assets/QuantumUser/View/Editor/LSDFStageBackgroundEditor.cs) 설정 편집과 `Refit Reference View` 메뉴는 기준 경계를 명시적으로 다시 맞춘다.
  이미지의 원본 비율·2P 반전·레이어 구분과 Ground 그림만 숨기는 동작은 유지한다.

줌아웃으로 넓은 영역이 보이는 것이 정상이다. 이미지 끝이 드러나면 `Minimum Height`로 기준 배경 크기를 키운다.
매 프레임 확대하여 빈 공간을 자동으로 감추는 동작은 제거했다. 새 다중 레이어 패럴랙스나 카메라 제어는 추가하지 않았다.
