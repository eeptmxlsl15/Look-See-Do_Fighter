# 멀리 날아가는 동안만 콜라이더 중심 설정

## 사용자 동작과 설정

`Assets/QuantumUser/Resources/LSDF_GameConfig.asset → Air Combo → 날아갈 때 콜라이더 위치`에서
5타 종료 또는 지정 마무리 기술로 날아가는 `BlownAway` 상태의 콜라이더 중심을 조절한다.

- 기본값은 기존 서 있는 중심과 같은 **X 0 / Y 0.01**이다. 새 기능을 추가해도 기본 플레이 위치는 유지한다.
- X를 높이면 오른쪽, Y를 높이면 위쪽이다. 월드축 기준이며 1P/2P별로 X를 반전하지 않는다.
- 엔티티 원점에 대한 콜라이더 중심의 절대 오프셋이다. 콜라이더 크기와 스프라이트 위치를 직접 변경하지 않는다.
- 첫 상승·일반 공중 재피격·느린 낙하·벽 상태에는 기존 서기/앉기 중심을 사용한다.
- 착지(하강 중 바닥 접촉), 회복, KO, 라운드 종료·초기화 때 원래 중심으로 복구한다.
  상승 중의 이전 바닥 접촉 표시만으로 중심을 일찍 복구하지 않는다.

## 구현

불변 `LSDFJuggleSettings.EnderColliderCenter`를 읽어 Frame의 `PhysicsCollider2D.Shape.LocalTransform`에 적용한다.
기존에는 크기가 달라질 때만 중심도 갱신했으므로, 같은 크기에서 중심만 바뀌는 경우에도 갱신하도록 수정했다.
새 설정값을 공유 에셋의 실행 상태로 쓰지 않는다. PlayerSystem 내부에서 Juggle의 착지/KO 전이를 먼저 처리한 뒤
확정된 상태에 맞춰 중심을 갱신한다. 바닥 접촉 표시만으로 날리기 중 중심을 번갈아 복구하지 않는다.

중심 복구로 바닥과 잠깐 떨어질 수 있다. 회복 중 바닥 접촉이 끊겨도 `BlownAway`로 재진입하지 않고
기존 회복 상태에서 원래 중력으로 재접촉을 기다린다. 날리기 중심을 다시 적용하는 접촉 반복을 막는다.
회복 시간 종료와 실제 바닥 접촉이 모두 만족돼야 종료하므로 공중에서 조작/추가 피격이 조기에 풀리지 않는다.

추가 상태/QTN/CodeGen/시스템 등록 변경은 없다. 물리→Player→Animator/명령 순서와 히트박스 수명은 유지했다.
PlayerSystem 안의 두 호출 순서만 `Collider → Juggle`에서 `Juggle → Collider`로 바꿨다.
설정/충돌 규칙을 서로 다른 실행 버전과 섞지 않도록 프로토콜을 `lsdf-loadout-v11-ender-collider-center`로 올렸다.
Config 에셋 ID와 기존 GUID, 낙하 시작 속도 0.3/가속도 0.5 등 사용자 설정, IDE 변경은 보존한다.

## 최종 한 차례 검증

정적 정책, diff 공백, Unity 컴파일, 중심만 변경·복구/각 공중 단계/바닥 접촉 방향/KO·라운드 종료/앉기/
공유 설정 격리 단위 검사와 기존 공중·마무리·라운드 회귀를 실행한다.

Photon 마무리 fixture는 세션 시작 전 메모리에서만 중심을 **X 0.02 / Y -0.05**로 바꾼다.
양쪽 관측자에서 5후속타 종료와 조기 마무리, 날리기 중심 적용·착지 회복 중심 복구를 관측하고,
확정 프레임 체크섬·입력 재생 2회·날리기 중심이 적용된 Frame 복원 후 재시뮬레이션을 비교한다.
fixture는 세션 종료 후 원래 Config를 복원하며 파일을 저장하지 않는다.

결과는 `evidence/ender-collider-center-validation.json`에 기록한다.

이 자동 검사 결과와 구별한다. 재생 복원 성공을 실제 네트워크 지연 rollback 성공으로 표현하지 않는다.
